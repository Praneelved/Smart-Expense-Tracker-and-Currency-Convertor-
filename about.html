System Architecture: Zero-Dependency Modern Web Application

Designed for speed, extreme portability, and instantaneous static deployment
Production Grade

SpendWise was engineered from the ground up to solve a frequent problem in contemporary web applications: massive bundle sizes, brittle npm dependency trees, and hydration lag. By adopting standard ECMAScript 2022+ Native ES Modules and CSS Custom Properties (Design Tokens), the entire application loads instantaneously, runs natively on any modern browser, and deploys effortlessly on static hosts such as GitHub Pages without requiring serverless compute or build runners.

1. Reactive Store Pattern

A centralized pub/sub store (store.js) manages state across all views. Mutations automatically persist to localStorage with schema migration validation, and trigger targeted DOM updates.

2. 3-Tier Currency Engine

Primary API queries Open Exchange Rates; fallback queries the European Central Bank (Frankfurter); secondary fallback reads from persistent cache; and ultimate fallback computes cross-rates from a verified reference snapshot.

3. Precise Decimal Arithmetic

Financial sums are computed using integer cents scaling (Math.round(val * 100)) before division, completely eradicating floating point rounding errors (e.g. 0.1 + 0.2 != 0.30000000000000004).

Modern JavaScript (ES6+) Features Utilized

Exemplifying professional engineering standards for Web Technologies II
  • ✓
    ES Modules (import / export): Clean separation of concerns across constants, store, currencyService, analytics, and ui.
  • ✓
    Async / Await & Promises: Asynchronous exchange rate resolution with AbortController timeouts to prevent hanging network requests.
  • ✓
    Destructuring & Rest/Spread: Immutable array and object manipulations when cloning transactions and updating settings.
  • ✓
    Higher-Order Array Methods: Declarative data pipelines utilizing filter(), map(), reduce(), find(), and sort().
  • ✓
    Template Literals & Interpolation: Dynamic DOM rendering without heavyweight virtual-DOM overhead or template engines.
  • ✓
    System MatchMedia Listeners: Automatic OS dark/light mode detection responding dynamically to operating system theme changes.

Security & Data Integrity Model

Protecting personal financial information with zero telemetry
Privacy by Design
100% Client-Side Storage

All financial ledger records, budgets, and personal salary entries live exclusively in your browser's sandboxed localStorage. No financial data is ever transmitted to a server or external party.

Input Sanitization & Validation

Form inputs are rigorously checked for numerical bounds and valid date formats. Exported CSV files escape special characters to mitigate CSV injection risks in spreadsheet applications.

Zero Secret Key Leaks

Currency conversion relies strictly on public open access endpoints without embedding private authorization tokens or credential keys in client bundles.
